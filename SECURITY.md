# Güvenlik politikası / Security policy

**Türkçe.** Güvenlik açığı bulduysanız lütfen herkese açık bir issue açmayın. Bunun yerine:

- GitHub'da **Security → Report a vulnerability** ile özel olarak bildirin, ya da
- `reachdevel@gmail.com` adresine yazın.

Bildirimi birkaç gün içinde yanıtlamaya çalışırız. `trblocked` bir ağ ölçüm aracıdır ve çalışma zamanı bağımlılığı yoktur; yine de aldığı girdiler (hedef adları, config dosyaları, ağdan gelen cevaplar) güvenilmez kabul edilir, bunlarla ilgili her türlü sorun kapsamdadır.

**English.** If you find a vulnerability, please do not open a public issue. Use **Security → Report a vulnerability** on GitHub, or email `reachdevel@gmail.com`. We aim to respond within a few days. Inputs (target names, config files, network responses) are treated as untrusted, so issues around them are in scope.

Desteklenen sürüm / Supported version: en son `1.x` / the latest `1.x`.
